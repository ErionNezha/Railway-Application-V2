# 🚂 Railway Application

Port web i aplikacionit Java Swing hekurudhor — rezervim biletash për pasagjerë dhe panel admini me PNR.

## 🚀 Si ta hapësh

Hap `index.html` — skeda **Live Demo** ekzekuton demo-n direkt në browser, skeda **Kodi Burim** tregon kodin e plotë (demo + origjinali i paprekur).
